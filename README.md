# ryanromanov/tap

Homebrew casks for two macOS apps:

- [Bitamp](https://github.com/ryanromanov/Bitamp), a skinnable audio player with an old-school look
- [Fallow](https://github.com/ryanromanov/fallow-writer), a distraction-free writing app with ambient sound

```
brew install --cask ryanromanov/tap/bitamp
brew install --cask ryanromanov/tap/fallow-writer
```

`brew upgrade` picks up new releases. Each one is signed and notarized by Apple.

Workflows here check for new releases every six hours and update each cask's version and checksum.
