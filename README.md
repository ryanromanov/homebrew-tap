# ryanromanov/tap

Homebrew casks for [Bitamp](https://github.com/ryanromanov/Bitamp), a skinnable audio player for macOS with an old-school look.

```
brew install --cask ryanromanov/tap/bitamp
```

`brew upgrade` picks up new releases. Each one is signed and notarized by Apple.

A workflow here checks for a new Bitamp release every six hours and updates the cask's version and checksum.
